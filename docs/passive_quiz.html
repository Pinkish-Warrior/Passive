Q1 — argparse
Why do we use add_mutually_exclusive_group(required=True) in argparse instead of three separate add_argument() calls?
passive.py
The Code:
28def build_parser():
29    # Only one flag allowed per run; all three are mutually exclusive
30    parser = argparse.ArgumentParser(
31        formatter_class=argparse.RawDescriptionHelpFormatter,
32        description=f"{BANNER}\n\n{OPTIONS}",
33        add_help=True,
34    )
35    group = parser.add_mutually_exclusive_group(required=True)
36    group.add_argument("-fn", metavar="FULL_NAME", help="Search by full name")
37    group.add_argument("-ip", metavar="IP_ADDRESS", help="Search by IP address")
38    group.add_argument("-u", metavar="USERNAME", help="Search by username")
39    group.add_argument("-ph", metavar="PHONE", help="Search by phone number (include country code, e.g. +33612345678)")
40    return parser
✓ Correct Answer: B
To prevent using -fn, -ip, and -u at the same time, and force the user to always pick one
📖 Explanation
The add_mutually_exclusive_group(required=True) method ensures:
  • ✓ User MUST choose exactly one flag
  • ✗ Cannot use passive -fn "John" -ip "8.8.8.8" — argparse raises an error
  • ✗ Cannot use passive with no flags — required=True enforces selection
  • ✓ Only one module runs per invocation, keeping logic clean
Q2 — output.py
Why does output.py use a while loop instead of just checking if result.txt exists once?
output.py
The Code:
 7def save_result(content: str) -> str:
 8    os.makedirs(OUTPUT_DIR, exist_ok=True)
 9    
10    filename = os.path.join(OUTPUT_DIR, "result.txt")
11    n = 2
12    
13    # Increment the suffix until we find a filename that doesn't exist yet
14    while os.path.exists(filename):
15        filename = os.path.join(OUTPUT_DIR, f"result{n}.txt")
16        n += 1
17    
18    with open(filename, "w") as f:
19        f.write(content + "\n")
20    
21    return filename
✓ Correct Answer: D
Because result2.txt, result3.txt... might also already exist from previous runs
📖 Explanation
The while loop is essential for sequential file naming:
  • 1st run: result.txt doesn't exist → write to result.txt
  • 2nd run: result.txt exists → loop once → write to result2.txt
  • 3rd run: result.txt and result2.txt both exist → loop twice → write to result3.txt
  • If we used if instead of while, it would only check once and overwrite result2.txt

Q4 — venv
Why did we create a venv/ folder instead of installing the project directly on the system Python?
Terminal commands
Virtual Environment Setup:
# Create virtual environment
$ python3 -m venv venv

# Activate it (venv name appears in prompt)
$ source venv/bin/activate
(venv) $

# Now install project dependencies INSIDE venv
(venv) $ pip install -r requirements.txt
(venv) $ pip install -e .

# The passive command is registered in venv/bin/
(venv) $ which passive
/path/to/project/venv/bin/passive
✓ Correct Answer: A
To keep project dependencies isolated from the system Python and avoid conflicts
📖 Explanation
Virtual environments prevent dependency conflicts:
  • Project A needs requests==2.28.0
  • Project B needs requests==2.31.0
  • Without venv → installing B breaks A
  • With venv → each project has its own isolated dependency set
  • System Python stays clean and stable
Q5 — ModuleNotFoundError
Why did passive --help fail with ModuleNotFoundError: No module named 'passive' even after running pip install -e .?
pyproject.toml (The Fix)
Required Configuration:
16[tool.setuptools]
17py-modules = ["passive", "output"]
✓ Correct Answer: C
Because pyproject.toml was missing the py-modules declaration so setuptools didn't know about passive.py
📖 Explanation
Without py-modules, setuptools doesn't know which files to include:
  • ✗ Missing py-modules → setuptools ignores passive.py and output.py
  • ✗ The passive command gets created in PATH, but it can't import the module
  • ✗ Result: ModuleNotFoundError: No module named 'passive'
  • ✓ Adding py-modules = ["passive", "output"] → setuptools knows to include these files
  • ✓ Now passive --help works!

Q8 — Soft 404
What is a "soft 404"?
HTTP Response Comparison
Hard 404 vs Soft 404:
# Hard 404 (Proper behavior)
GET /user/nonexistentuser123
HTTP/1.1 404 Not Found
Content-Type: text/html

<h1>User not found</h1>

# Soft 404 (Problematic for scraping)
GET /user/nonexistentuser123
HTTP/1.1 200 OK  <-- Claims success!
Content-Type: text/html

<h1>Sorry, this user doesn't exist</h1>
# ↑ Message says "not found" but status is 200
✓ Correct Answer: B
A page that returns HTTP 200 but shows a "not found" message
📖 Explanation
Soft 404s break automated detection:
  • Your code checks if response.status_code == 200: → thinks user exists
  • Reddit does this on profile pages → always returns 200
  • Solution: Check page content or use API endpoints that return real 404s
  • Reddit fix: Use /user/{username}/about.json which returns proper 404
Q9 — Reddit false positives
Why did Reddit return yes for a fake username in our first attempt?
The Problem:
# ✗ This always returns 200, even for fake users
url = f"https://www.reddit.com/user/{username}"
response = requests.get(url)
if response.status_code == 200:
    return "yes"  # ← False positive!
✓ Correct Answer: C
Reddit returns HTTP 200 even for non-existent users on the profile page
📖 Explanation
Reddit's HTML profile pages are soft 404s - they return 200 OK regardless of whether the user exists or not. This is common on modern web platforms designed for browsers rather than bots.
Q10 — Reddit fix
How did we fix Reddit's false positives?
The Fix:
# ✓ The JSON API returns proper 404 for non-existent users
url = f"https://www.reddit.com/user/{username}/about.json"
response = requests.get(url)
if response.status_code == 404:
    return "no"   # ← Accurate!
elif response.status_code == 200:
    return "yes"  # ← Accurate!
✓ Correct Answer: C
Used the /user/{}/about.json API endpoint which returns a real 404
📖 Explanation
JSON APIs are designed for bots and return proper HTTP status codes. The /about.json endpoint returns 200 + user data if exists, 404 if not.
Q11 — Why Playwright
Why did we add Playwright for Twitter/X, Instagram, and Pinterest?
